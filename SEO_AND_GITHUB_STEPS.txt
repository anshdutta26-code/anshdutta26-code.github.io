PART B — GOOGLE SEARCH CONSOLE (DO AFTER SITE IS LIVE)
1. Open Google Search Console.
2. Add a Domain property: anshdutta.com
3. Google will give you a TXT DNS verification value.
4. In GoDaddy -> DNS -> Add New Record -> Type TXT.
5. Host/Name: @
6. Value: paste Google's verification value exactly.
7. Save, return to Search Console and click Verify. DNS propagation can take time.
8. In Search Console -> Sitemaps, submit: sitemap.xml
9. Use URL Inspection and Request Indexing for these first:
